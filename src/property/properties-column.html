Property label Definition Property URI Range Cardinality Usage note
name A technical name given to the Variable as it appears in the CSV file. csvw:name rdfs:Literal 1..n Technical variable name required to match a column header in the CSV file (synthetic, anonymized representation of the real data), can appear in multiple languages.
title A human-readable name given to the Variable. csvw:title rdfs:Literal 1..n Human-readable title(s) for the column. May be multilingual.
description Variable description. dct:description rdfs:Literal 1..n Used to provide human-readable information about the variable (column). Can appear in multiple languages. This is especially helpful for variable documentation.
datatype Specifies the expected datatype of the values in the column. csvw:datatype rdfs:Literal 1 Should match the label of one of the CSVW types as defined in the Built-in datatypes from XML Schema. https://w3c.github.io/csvw/metadata/#datatypes Example: string, integer, boolean …

Controlled vocabulary
The use of the specified vocabulary is optional, but recommended when applicable.

https://w3c.github.io/csvw/metadata/#datatypes
property URL A URI template used to define the RDF predicate associated with the values in the column, relative to each row. csvw:propertyUrl rdfs:Literal (IRI) 0..1 The propertyUrl may point to standard, controlled vocabularies, or ontologies that define the semantic meaning of the column.
For example: csvw:propertyUrl http://publications.europa.eu/resource/authority/country

For advanced usage, refer to the official specification: www.w3.org/TR/tabular-metadata/#propertyurl
